Data source & formulas

Source: GameChanger box scores, extracted Oct 18, 2026. Season-stats page on GameChanger is paywalled placeholder data and was ignored; all stats are computed from the box scores.

AVG = H/AB · OBP = (H+BB+HBP)/(AB+BB+HBP+SF) · SLG = TB/AB · OPS = OBP+SLG · K% = SO/PA · PA = AB+BB+HBP+SF+SAC · 1B = H−2B−3B−HR · ERA = ER×7/IP (7-inning games) · WHIP = (BB+H)/IP · K/7 = SO×7/IP · BB/7 = BB×7/IP · P/IP = pitches/IP · Strike % = strikes/pitches. IP shown as innings.outs. “-” = not computable.
